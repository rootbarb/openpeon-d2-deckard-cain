A [peon-ping](https://github.com/PeonPing/peon-ping) sound pack featuring **Deckard Cain** from Diablo II.

## Sounds

| Category | Clips |
|---|---|
| `session.start` | "Stay a while and listen!", "Hello, my friend...", "Hello.", "Greetings." |
| `task.acknowledge` | "Yes.", plus 3 help responses |
| `task.complete` | "Good to see you.", "Good day.", "Good morning.", "Farewell." |
| `task.error` | "Need help?", "Goodbye." |
| `input.required` | "Stay a while and listen!", "Need help?", "Hello.", "Good evening." |
| `resource.limit` | "Farewell.", "Goodbye." |
| `user.spam` | "Goodbye.", "Farewell.", "Good evening." |

## Install

```bash
peon packs add rootbarb/openpeon-d2-deckard-cain
peon packs use d2_deckard_cain
```
